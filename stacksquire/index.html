Inside the app

One clear path to interview‑ready, with practice at every step

Every lesson leads to something to do: a quiz, a flashcard, a challenge to code or a visualization to step through.

Learning paths

Six skill trees, one clear route

Programming, Algorithms, Databases, Operating Systems, Architecture and Networking: 56 skill nodes linked by prerequisites, so you always know what to study next. Each node brings its lesson, quiz, flashcards and practice together in one place.

  • 50 lessons in 178 short sections
  • Mastery blends accuracy, confidence, card recall and freshness
  • Finished skills unlock the next ones
Coding practice

Write Python. Run it offline.

39 coding and debugging challenges with hidden tests. Your code runs on the device in a sandboxed subset of Python 3, written in pure Dart, so practice works with no server, no account and no connection.

  • Functions, classes, comprehensions, exceptions and f-strings, plus parts of collections, heapq, itertools and more
  • No file, network or process access, with step, memory and time limits
  • Matches CPython on the project's conformance suite (a subset, not full CPython)
Visualizations

Watch algorithms think

11 step-through visualizations you can play, pause, step and speed up: sorting, binary search, tree and graph traversal, recursion, stacks and queues, dynamic programming, memory allocation, CPU scheduling, deadlocks and SQL joins.

  • A caption explains every step, with speed control and a timeline you can scrub
  • Opened straight from the skills they explain
Boss battles

Prove it in a boss battle

Six bosses guard the skill trees. The Big-O Basilisk, for one, sets five trials, from predicting output to a timed coding challenge, with three hearts to lose. Win, and the next skills open up.

  • XP and levels, daily and weekly quests, achievements
  • Streaks with freezes, and a daily coding challenge
Developer Mode

Practise the job, not just the interview

Seven tickets modelled on real work: review a teammate's pull request and flag the real problems, fix bugs that span several files, refactor safely, and write unit tests graded by mutation testing.

  • Security, performance and readability issues to find
  • False alarms cost points, just like a real review

FAQ

Questions

Can I download StackSquire?

Not yet. StackSquire is finished but unpublished, and it's for sale. Its new owner will publish it for Windows, Android and iOS.

Does it need an internet connection?

No. Lessons, quizzes, flashcards, coding challenges and visualizations all work offline. An account is optional and only syncs progress between devices.

Is it real Python?

It's a sandboxed subset of Python 3, written in Dart so it runs safely on any device without a server. It matches CPython on the project's conformance suite, but it isn't full CPython and doesn't include the whole standard library.

How does the sale work?

An asset purchase agreement, with payment held in escrow. The GitHub repository is transferred, and the Firebase project too if you want it. Acceptance checks run in an agreed window, escrow releases payment, and two weeks of setup support begin.
